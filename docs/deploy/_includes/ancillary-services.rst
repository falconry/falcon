In addition to setting up NGINX and the application server to run your
application, you will of course need to deploy a database server or any other
services required by your application. Due to the wide variety of options and
considerations in this space, we have chosen not to include ancillary services
in this guide. However, the Falcon community is always happy to help with
deployment questions, so
`please don't hesitate to ask <https://falcon.readthedocs.io/en/stable/community/help.html#chat>`_.
