An optional `allow_multiple` keyword argument was added to the query string
parameter helpers (:meth:`~falcon.Request.get_param`,
:meth:`~falcon.Request.get_param_as_bool`,
:meth:`~falcon.Request.get_param_as_date`,
:meth:`~falcon.Request.get_param_as_datetime`,
:meth:`~falcon.Request.get_param_as_dict`,
:meth:`~falcon.Request.get_param_as_float`,
:meth:`~falcon.Request.get_param_as_int`,
:meth:`~falcon.Request.get_param_as_json`,
:meth:`~falcon.Request.get_param_as_media`, and
:meth:`~falcon.Request.get_param_as_uuid`).

When it is set to ``False``, and the parameter resolves to more than one value,
an :class:`~falcon.HTTPInvalidParam` error is raised instead of picking an
arbitrary one of those values (default ``True``).
