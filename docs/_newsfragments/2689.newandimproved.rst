A new :attr:`~falcon.RequestOptions.max_content_length` request option was
added to provide an easy way to limit the size of request bodies. When it is
set, requests declaring a Content-Length larger than the limit are rejected with
:class:`~falcon.HTTPContentTooLarge` before any request middleware or responder
is invoked. In ASGI apps, the limit is also enforced while reading a request
body of unknown length, in which case the error is raised from the request
stream as soon as the limit is exceeded. The option is disabled by default.
